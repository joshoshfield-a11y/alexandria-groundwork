## Hardened spec

1. **State space:** subsets A of a topological space X.
2. **Computable form:** the topological boundary ∂A = closure(A) ∩ closure(X \ A) — points approachable from both inside and outside A. Worked example: A = (0, 1] ⊂ ℝ. closure(A) = [0, 1]; closure(ℝ \ A) = (−∞, 0] ∪ (1, ∞); hence ∂A = {0, 1}. For a manifold, ∂M is the set where charts map to the half-space boundary — e.g., the boundary of the open disk is the circle S¹.
3. **Measurable quantity:** boundary length in meters (m) for surveyed regions, or a dimensionless count of boundary components. Instrument: survey/GPS trace of the perimeter; in imaging, edge-detection pixel counts calibrated to scale.
4. **Standard theory:** point-set topology (Munkres); Stokes' theorem, which is fundamentally a statement about boundaries (∫_M dω = ∫_{∂M} ω).
