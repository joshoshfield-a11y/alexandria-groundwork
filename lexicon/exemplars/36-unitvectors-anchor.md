## Hardened spec

1. **State space:** a vector space V over ℝ or ℂ (finite
   dimension d for the exemplar), with the unit sphere
   {u : ‖u‖ = 1} as the domain.
2. **Computable form:** normalization û = v/‖v‖; ‖û‖ = 1 by
   construction. Worked example: v = (3, 4), ‖v‖ = 5 →
   û = (0.6, 0.8); any vector decomposes as v = ‖v‖·û.
3. **Measurable quantity:** direction is dimensionless — a point
   on S^(d−1). Physical direction (e.g. a magnetic-field unit
   vector) is measured as angles in radians/degrees; instrument:
   goniometer, compass, fluxgate magnetometer for the vector
   itself, then normalized.
4. **Standard theory:** linear algebra — normed vector spaces;
   the standard basis {e_i} is a set of unit vectors. Dirac kets
   |ψ⟩ with ⟨ψ|ψ⟩ = 1 are the quantum case.
5. **Prediction differing from standard theory:** none.
