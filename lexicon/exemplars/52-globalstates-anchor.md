## Hardened spec

1. **State space:** the full Hilbert space of a composite system,
   ℋ = ⊗_i ℋ_i; the global state is a density matrix ρ on ℋ
   (pure state |Ψ⟩⟨Ψ| or mixed). Local states are the reduced
   matrices ρ_A = Tr_B(ρ).
2. **Computable form:** Bell state |Φ⁺⟩ = (|00⟩+|11⟩)/√2 →
   global ρ = |Φ⁺⟩⟨Φ⁺|, a 4×4 rank-1 matrix; reduced state
   ρ_A = Tr_B(ρ) = I/2 — locally maximally mixed while the
   global state is pure. Global vs. local is quantified by the
   entanglement entropy S(ρ_A) = −Tr(ρ_A log ρ_A).
3. **Measurable quantity:** state fidelity F = Tr√(√ρσ√ρ)
   (dimensionless, 0–1); tomographic density-matrix entries.
   Instrument: quantum state tomography (complete Pauli-basis
   measurements).
4. **Standard theory:** quantum information theory of composite
   systems — partial trace, Schmidt decomposition, entanglement
   measures. Classically: the joint distribution P(x₁,…,x_n)
   with marginals as the analogue.
5. **Prediction differing from standard theory:** none.
